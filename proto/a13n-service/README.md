# Service contract exports

Generated from the new `a13n_service.app.build_app` by `make service-contract-generate`. The export currently contains operational probes only. No run event schemas or wire fixtures are advertised before execution/observation is implemented. Historical exports are isolated in `../a13n-service-legacy` and must never be generation inputs.

Console types are regenerated from this OpenAPI file. Existing Console flows still require replacement and are not supported by this foundation. Independent SDK and remote CLI repositories must adapt their own clients after the new API is implemented.
