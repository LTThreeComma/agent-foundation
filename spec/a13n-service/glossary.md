# Glossary

One word, one meaning. If a new word is needed, add it here first.

| Word                    | Meaning                                                                                                                                                                                     | Not                                                                          |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| **organization**        | the billing and administration boundary                                                                                                                                                     | a tenant of the Console only                                                 |
| **workspace**           | the resource and work boundary inside an organization                                                                                                                                       | a directory, a sandbox                                                       |
| **principal**           | a user or a service account; the thing grants and credentials attach to                                                                                                                     | an actor in the audit sense only                                             |
| **credential**          | what proves a request is a principal: a password, an API key, or a token                                                                                                                    | a provider's secret (that is a `credential` column, see below)               |
| **API key**             | a bearer credential representing a user or service account, always confined to one workspace; effective permissions are its principal's current grants intersected with that scope          | an organization/global key, a grant of administrator rights                  |
| **token**               | a short-lived secret looked up by hash: login session, password-reset link, email-change link                                                                                               | an API key, an OAuth token                                                   |
| **grant**               | a role given to a principal in an organization or a workspace                                                                                                                               | a role binding (old word)                                                    |
| **role**                | a named set of verbs; four built-ins plus distribution definitions                                                                                                                          | a permission, an action                                                      |
| **verb**                | read, run, write, admin; what `authorize` checks                                                                                                                                            | an operation name                                                            |
| **resource**            | anything a tenant configures under `resources/`: agents, skills, templates, providers, models, connections, secrets, assets, subscriptions                                                  | a run, a thread, an HTTP resource in general                                 |
| **revisioned**          | a resource lifecycle: an archivable head with immutable numbered revisions that runs freeze                                                                                                 | versioned by ETag                                                            |
| **live**                | a resource lifecycle: a mutable definition, resolved and authorized at use                                                                                                                  | cached                                                                       |
| **revision**            | an immutable, numbered configuration of a revisioned resource                                                                                                                               | a version, a generation, a draft                                             |
| **provider resource**   | a tenant-configured backend record under `resources/`, with ID, scope, `type`, `config`, credential and enabled state: model, environment, web                                              | an adapter or a live client                                                  |
| **provider definition** | schemas, supported operations and a typed factory for an implementation, registered by `(kind, type)`                                                                                       | a tenant-configured resource                                                 |
| **provider handle**     | a runtime backend object built from validated configuration and credentials, with a lifetime owned by its caller                                                                            | a database row or a registered definition                                    |
| **connection**          | a configured source of tools: an MCP server or a Composio app                                                                                                                               | a network connection, a WebSocket                                            |
| **authorization**       | one principal's OAuth grant and credential generation on one connection                                                                                                                     | the act of authorizing (that is `authorize`)                                 |
| **secret**              | an opaque value a tenant stores and never reads back; resolved for tools by requirement key                                                                                                 | a provider credential, a signing secret                                      |
| **credential (column)** | the encrypted write-only secret of a provider resource or connection                                                                                                                        | a tenancy credential                                                         |
| **asset**               | immutable content with metadata                                                                                                                                                             | a file in an environment                                                     |
| **subscription**        | a webhook: event kinds, filter, URL, signing secret                                                                                                                                         | a hook (old word), a stream subscriber                                       |
| **session**             | a group of threads; one conversation in the Console                                                                                                                                         | a login session (that is a credential of kind `session`), a database session |
| **thread**              | one independently advancing history; owns its inbox and environments                                                                                                                        | a conversation, an OS thread                                                 |
| **inbox**               | a thread's input records, selected by state eligibility then position; ordinary pending and assigned inputs occupy [capacity](05-runs.md#inbox-capacity), with a control-feedback exception | an unconditional FIFO or a separate queued-submission table                  |
| **offered**             | a worker-local fact that an input was queued to this Harness instance; never a durable entry status                                                                                         | consumed                                                                     |
| **assigned**            | an immutable input bound to one run, surviving attempt replacement                                                                                                                          | incorporated or successful                                                   |
| **consumed**            | an entry with durable checkpoint incorporation confirmed in PostgreSQL before a winning terminal disposition                                                                                | merely an object-only receipt, proof that the run succeeded                  |
| **receipt**             | host evidence linking an entry to incorporated resumable state                                                                                                                              | enqueue acknowledgement                                                      |
| **entry**               | one inbox row: message, feedback or child result                                                                                                                                            | a queued submission, a steer (those are `delivery` values)                   |
| **feedback**            | an inbox kind carrying approval decisions or client-tool results for an exact waiting run and its tool calls; [05](05-runs.md#waiting-interrupt-and-fork) defines normalization             | ordinary conversation text or a model-facing tool                            |
| **user input wait**     | a pending `ask_user_question` call; ordinary messages can continue a question-only wait                                                                                                     | approval to execute a tool                                                   |
| **approval**            | a decision required before a specific tool call may execute; the waiting run identifies which suspension of that call is being answered                                                     | a question asked through `ask_user_question`                                 |
| **client tool**         | a tool whose result is supplied by an external client through feedback                                                                                                                      | an unanswered user question                                                  |
| **infra**               | shared database, storage, transport, audit, outbox and scheduling mechanisms under `infra/`, without business-package dependencies                                                          | startup assembly or a home for business handlers                             |
| **answer**              | one feedback result identified by `tool_call_id`: an approval decision or a client-tool result                                                                                              | ordinary text replying to a user question                                    |
| **payload**             | an entry's typed content selected by its `kind`; inline or held by `payload_ref` in storage                                                                                                 | a second execution state or an arbitrary untyped JSON bag                    |
| **delivery**            | how an entry reaches a running run: steer now, or next run                                                                                                                                  | webhook delivery (that is an outbox row)                                     |
| **run**                 | one accepted advancement of a thread with one agent revision                                                                                                                                | an attempt, a Harness run                                                    |
| **attempt**             | one fenced execution of a run by one worker                                                                                                                                                 | a retry                                                                      |
| **fence**               | the current attempt identity plus worker/token/status/unexpired-lease predicate                                                                                                             | a lock, a lease                                                              |
| **lease**               | a worker's time-bounded right to execute an attempt, renewed by heartbeat                                                                                                                   | a fence                                                                      |
| **checkpoint**          | resumable Harness state and cumulative receipts, durably replaced at the run's fixed state key with object-version CAS                                                                      | a display snapshot, a database savepoint, a historical file per sequence     |
| **display snapshot**    | durably folded observations with attempt segments and a cursor; may advance independently of resumable state                                                                                | the stream, a projection of the checkpoint                                   |
| **stream**              | the bounded, provisional Redis feed of one attempt's observations                                                                                                                           | the facts, the display snapshot                                              |
| **boundary**            | the moment between one model request and the next, where the worker checkpoints, ingests usage and reads the inbox                                                                          | a turn                                                                       |
| **accept**              | the decision and insert that creates a run from an entry                                                                                                                                    | submit                                                                       |
| **submit**              | append an entry to a thread's inbox and try to accept                                                                                                                                       | start, continue (old words)                                                  |
| **claim**               | a worker taking an accepted run and creating an attempt                                                                                                                                     | scheduling                                                                   |
| **execute**             | running the Harness for an attempt                                                                                                                                                          | process, drive                                                               |
| **seal**                | the transaction that records a terminal outcome or yields an attempt; successor/parent work follows durably                                                                                 | commit, finalize, outcome                                                    |
| **head**                | this thread's latest completed/waiting run; initial-history fallback is defined in [05](05-runs.md#source-selection)                                                                        | the current run or a failed run                                              |
| **current run**         | the run of a thread in `accepted` or `running`                                                                                                                                              | the head                                                                     |
| **event**               | an immutable fact about a run or attempt status change                                                                                                                                      | a stream entry, an audit event, a hook event                                 |
| **usage record**        | one immutable Harness usage report                                                                                                                                                          | a cost, a budget                                                             |
| **outbox**              | durable delivery intents: webhook, child result or identity email                                                                                                                           | events, object reclamation                                                   |
| **sweep**               | a periodic background function that finds its work by a `WHERE` clause                                                                                                                      | a job, a reconciler, a publisher                                             |
| **environment**         | a sandbox instance selected by thread mounts, possibly shared                                                                                                                               | a template, a provider, a deployment environment                             |
| **template**            | what an environment is created from                                                                                                                                                         | an agent template                                                            |
| **mount**               | one environment attached to a thread under a name                                                                                                                                           | a live mount (old word)                                                      |
| **mcp_headers**         | frozen context keyed by connection ID; inheritance and effective comparison are defined in [04](04-resources.md#caller-headers)                                                             | authentication or a tool grant                                               |
| **distribution**        | typed contributions to assembly, including roles and additional admission policy                                                                                                            | an edition, a plugin                                                         |
| **role (process)**      | `all`, `control`, `worker`                                                                                                                                                                  | a tenancy role                                                               |
| **authority**           | persisted execution ceiling intersected with current principal/grants                                                                                                                       | the worker's own credentials                                                 |
| **recovery**            | replacement attempt claims the same run's latest durable checkpoint and confirms receipts before continuing                                                                                 | resubmission of the input, reversal of a failed/cancelled seal               |
| **operation**           | one environment/OAuth external action with a durable identity and known or unknown outcome                                                                                                  | permission to repeat after timeout                                           |
| **generation**          | monotonic invalidation/version boundary for an external operation's result                                                                                                                  | attempt number or resource ETag                                              |
| **desired mount**       | a thread's selection for future runs                                                                                                                                                        | current active-use evidence                                                  |
| **accepted mount**      | immutable run selection, pinning active use while accepted/running                                                                                                                          | separate environment ownership                                               |
| **workspace cursor**    | commit-ordered lifecycle position within one workspace                                                                                                                                      | global sequence, timestamp, or Redis cursor                                  |
| **call ID**             | identity of one paid external call, shared by the admission check and its usage record                                                                                                      | a new ID on usage redelivery                                                 |
